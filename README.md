# AudioBooks Player 0.1

Минимальный локальный MP3-плеер для iPhone.

## Что умеет

- автоматически создаёт папку `Books`;
- ищет первый MP3-файл в `Books`;
- Play / Pause;
- перемотка по полосе времени;
- отображение текущего времени и длительности;
- отдельная громкость плеера;
- подготовленное фоновое аудио;
- папка Books доступна через приложение «Файлы».

## Как пользоваться

1. Установить приложение на iPhone.
2. Открыть «Файлы».
3. Перейти: На iPhone -> AudioBooks -> Books.
4. Скопировать туда MP3.
5. Открыть AudioBooks.
6. Нажать «Обновить Books».
7. Нажать Play.

Пока приложение специально берёт только первый MP3-файл.
